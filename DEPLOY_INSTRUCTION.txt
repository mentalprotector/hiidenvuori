ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES

1. npm ci
2. npm run build
3. npm run verify
4. После проверки отправьте коммит в master или main.

GitHub Actions публикует только каталог _site.
CNAME и .nojekyll включаются в сборку автоматически.
Не меняйте DNS и не запускайте публикацию без согласования с владельцем сайта.
